# BTC Price Tracker iOS App

## 项目简介

这是一个iOS应用，用于实时追踪比特币(BTC)价格，同时显示美元(USD)和人民币(CNY)价格，并提供动态价格曲线图。

## 功能特性

### 🚀 核心功能
- **实时价格查询**: 每30秒自动更新BTC最新价格
- **双币种显示**: 同时显示USD和CNY价格
- **动态图表**: 实时价格曲线图，支持USD/CNY切换
- **价格统计**: 显示最高价、最低价、平均价
- **手动刷新**: 支持下拉刷新和按钮刷新

### 📱 用户界面
- **现代化设计**: 采用SwiftUI构建，界面简洁美观
- **响应式布局**: 支持iPhone和iPad
- **实时动画**: 刷新动画和数据更新动画
- **错误处理**: 友好的错误提示和处理

### 📊 数据可视化
- **价格曲线图**: 使用Swift Charts框架
- **历史数据**: 保存最近100个价格点
- **统计信息**: 实时计算价格统计数据
- **货币切换**: 图表支持USD/CNY价格切换

## 技术架构

### 🛠 技术栈
- **开发语言**: Swift 5.0+
- **UI框架**: SwiftUI
- **图表库**: Swift Charts
- **网络请求**: URLSession + Combine
- **数据源**: CoinGecko API
- **最低版本**: iOS 16.0+

## API接口

### 数据源
- **API提供商**: CoinGecko
- **接口地址**: `https://api.coingecko.com/api/v3/simple/price`
- **查询参数**: `ids=bitcoin&vs_currencies=usd,cny`
- **更新频率**: 30秒
- **免费额度**: 无需API Key，有请求限制

### 数据格式
```json
{
  "bitcoin": {
    "usd": 45000.0,
    "cny": 320000.0
  }
}
```

4. 选择目标设备或模拟器
5. 点击运行按钮 (⌘+R)

- **Bundle Identifier**: `com.example.BTCPriceTracker`
- **Deployment Target**: iOS 16.0
- **Swift Version**: 5.0
- **支持设备**: iPhone, iPad

## 使用说明

### 主要操作
1. **查看实时价格**: 应用启动后自动获取最新价格
2. **刷新数据**: 点击右上角刷新按钮或下拉刷新
3. **查看图表**: 滚动到图表区域查看价格走势
4. **切换货币**: 在图表上方选择USD或CNY
5. **查看统计**: 图表下方显示价格统计信息

### 功能说明
- **自动更新**: 应用会每30秒自动获取最新价格
- **离线提示**: 网络异常时会显示错误提示
- **数据缓存**: 保留最近100个价格点用于图表显示
- **格式化显示**: 价格按照对应货币格式显示
